## Project Title

Blood Bank Donation and Issue Management System

## Description

A web-based DBMS application for managing blood donors, patients, hospitals, donations, blood inventory, blood requests and blood issues using Flask, MySQL, HTML, CSS and JavaScript.

## Technologies Used

- Python
- Flask
- MySQL
- MySQL Workbench
- HTML5
- CSS3
- JavaScript
- mysql-connector-python
- python-dotenv

## Main Modules

- Donor Management
- Patient Management
- Hospital Management
- Blood Donation Management
- Blood Inventory Management
- Blood Request Management
- Blood Issue Management
- Dashboard and Statistics

## Database

Database Name:

`blood_bank_management_system`

The database contains tables for:

- Blood Groups
- Donors
- Hospitals
- Patients
- Donations
- Blood Inventory
- Blood Requests
- Blood Issues

## DBMS Features

The project demonstrates:

- Primary Keys
- Foreign Keys
- UNIQUE Constraints
- CHECK Constraints
- ENUM
- SQL JOINs
- Aggregate Queries
- Views
- Triggers
- CRUD Operations
- Flask–MySQL Connectivity
